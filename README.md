One line, at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline.

## Run it

```sh
node main.ts
```

## What it writes

`main.ts` writes one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`): the agent's excuse to its human, 116 characters, no
trailing newline. It self-checks the 1–200 character gate before writing
and throws rather than producing an invalid entry.
